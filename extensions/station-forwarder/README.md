# Station SMB forwarder (experimental)

This component maintains a fixed IPv4 TCP forwarding and SNAT rule set for one source host, one destination host, and one port. It requires host networking, `CAP_NET_ADMIN`, an `iptables` binary using the host's actual backend, enabled IPv4 forwarding and an existing SNAT address on the named output interface. It checks these prerequisites before applying rules. It inserts narrowly matched `FORWARD` rules and appends a matching `POSTROUTING` SNAT rule; it does not change the global forwarding switch or firewall policy. Other host chains or firewall hooks may still deny traffic. Preserve an independent administration path.

Configuration is one JSON object with `input`, `output`, `source`, `destination`, `snat` (all addresses are single unicast IPv4 addresses) and `port` (TCP). A SHA-256 fingerprint is pinned in `/var/lib/rlark-station-forwarder/config.sha256` before effects; each instance must have a dedicated persistent hostPath. Restarts accept only the identical configuration. The program never removes firewall rules, including on Pod deletion; rules remain until reboot or explicit removal. To change or uninstall, first record and remove only the exact three rules in the independently administered host firewall, verify absence and then remove the corresponding fingerprint state. Do not remove unrelated rules or infer ownership from the comment alone. Partial failure may leave a subset of rules applied; reapplying the same configuration retries. Rule verification currently checks exact presence, not whether another chain supersedes the rule. This component does not authenticate SMB users; SMB credentials and authorization are enforced by the NAS.

The image contains iptables and is tied to the host's backend compatibility. In this deployment it is cached locally with `imagePullPolicy: Never`; image loss prevents automatic recovery. Validate traffic and denial paths, node restart, failed rules, storage authentication and operator recovery before relying on it. Unit and isolated kernel rule tests: `GOWORK=off go test ./...`, `GOWORK=off go vet ./...`, `unshare -Urn env GOWORK=off STATION_NETNS_TEST=1 go test -run TestFirewallIdempotence ./...`.

The three-namespace forwarding and denial test is `unshare -Urnm sh tests/network-namespace.sh`.
